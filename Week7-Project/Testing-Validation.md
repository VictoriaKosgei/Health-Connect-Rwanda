# HealthConnect Rwanda – Week 7 Testing Plan

## 1. Project Information

- **Project:** HealthConnect Rwanda Healthcare Analytics
- **Program:** AnalystLab Africa Internship
- **Track:** Data Analytics
- **Phase:** Week 7 – Testing, Validation and Refinement
- **Intern:** Victoria Kosgei
- **Date:** November 2026

## 2. Purpose

The purpose of Week 7 is to test, validate and refine the HealthConnect Rwanda analytics solution developed during Week 6.

The testing process focuses on confirming the accuracy of analytical KPIs, checking data quality, testing dashboard functionality, validating business findings and identifying limitations that may affect decision-making.

## 3. Testing Objectives

The objectives are to:

1. Validate key financial and operational KPIs.
2. Compare dashboard figures against underlying source data.
3. Investigate unmatched records and data-quality issues.
4. Test dashboard filters, slicers and navigation.
5. Validate analytical findings against available data.
6. Review dashboard clarity and identify areas requiring refinement.
7. Participate in cross-track testing with the Data Science track.
8. Document limitations and outstanding issues for Week 8.

## 4. Testing Scope

The testing covers:

- KPI calculations and financial measures.
- Appointment and billing data relationships.
- Department ID consistency.
- Patient demographic analysis.
- Insurance claim analysis.
- Diagnosis and chronic-condition analysis.
- Dashboard interactions and navigation.
- Data Science model-testing findings.

## 5. Testing Approach

The following approach was adopted:

| Testing Area | Testing Method |
|---|---|
| KPI validation | Recalculate measures and compare with dashboard results |
| Data quality | Check matching, unmatched and blank identifiers |
| Dashboard testing | Interact with slicers, filters, charts and navigation |
| Analytical validation | Compare findings with available source data |
| Cross-track testing | Review Data Science model-testing findings |
| Refinement | Identify misleading visuals, weaknesses and limitations |

## 6. Expected Outcome

The expected outcome is a more reliable and validated healthcare analytics solution, with documented KPI results, data-quality findings, dashboard testing results, cross-track findings and recommendations for Week 8.
