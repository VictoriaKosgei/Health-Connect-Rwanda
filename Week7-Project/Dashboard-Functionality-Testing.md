# HealthConnect Rwanda – Dashboard Functionality Testing

## 1. Purpose

This document records the functionality testing performed on the HealthConnect Rwanda six-page interactive Power BI dashboard.

The objective was to confirm that dashboard interactions worked as expected and that users could explore the available analytical information.

## 2. Testing Results

| Test Area | Expected Behaviour | Result |
|---|---|---|
| Date Slicer | Filters dashboard information by date | Pass |
| Department Slicer | Filters information by department | Pass |
| Gender Slicer | Filters demographic information | Pass |
| KPI Cards | Respond to applicable filters | Pass |
| Chart Cross-Filtering | Selecting a chart element filters related visuals | Pass |
| Page Navigation | Users can move between dashboard pages | Pass |
| Reset/Clear Filters | Users can clear applied filters | Pass |

## 3. Testing Approach

The dashboard was tested by interacting with the available slicers, charts, KPI cards and navigation controls.

The tests focused on checking whether:

- Filters affected the relevant dashboard visuals.
- KPI cards responded to applicable selections.
- Charts interacted correctly with other visuals.
- Navigation between dashboard pages worked.
- Applied filters could be cleared or reset.

## 4. Results

All the listed dashboard interactions were reported to work as expected during testing.

No interaction failure was reported in the completed checks.

## 5. Conclusion

The dashboard functionality tests passed based on the interactions performed.

The dashboard remains available for the final review and any additional refinements identified during the remaining Week 7 activities.
